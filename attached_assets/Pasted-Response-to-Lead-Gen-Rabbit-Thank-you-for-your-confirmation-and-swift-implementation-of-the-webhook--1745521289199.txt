Simplified Integration Option
To help streamline our integration, we're now offering a simplified approach that preserves quality while reducing implementation complexity. This simplified integration is available to all our partners as an alternative option:

Simplified Request Format
{
  "query": "The search query string",
  "callbackUrl": "https://our-platform.example.com/api/webhook"
}
Simplified Response Format
{
  "searchId": "unique-identifier",
  "status": "completed",
  "results": {
    "companies": [
      {
        "name": "Company Name",
        "website": "https://example.com",
        "industry": "Technology",
        "location": "New York, NY"
      }
    ],
    "contacts": [
      {
        "name": "John Smith",
        "role": "CEO", 
        "email": "john.smith@example.com"
      }
    ]
  }
}
With this simplified approach:

Incremental updates become optional
Only final results are required
Required fields are minimized to essentials
Please note: This simplified integration doesn't compromise on data quality - we still expect high-quality company and contact data. It simply reduces the protocol overhead.
