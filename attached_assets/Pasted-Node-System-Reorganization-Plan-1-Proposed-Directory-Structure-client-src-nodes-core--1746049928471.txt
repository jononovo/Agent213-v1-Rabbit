3. Files to Be Split
The unifiedNodeRegistry.ts file contains multiple responsibilities and should be split into:

nodeRegistry.ts - Core registry functionality
nodeDiscovery.ts - Node discovery logic
nodeValidation.ts - Node validation logic
4. Files/Directories to Be Removed
client/src/nodes/components/ (after moving contents)
client/src/nodes/_node_templates/ (after moving contents)
client/src/nodes/Base/ (after moving contents)
Empty directories after migration
5. Code Refactoring
After moving files, imports in each file will need to be updated to reflect the new structure. For example:

// Old import
import { BaseNode } from '@/nodes/Base';
// New import
import { BaseNode } from '@/nodes/core/base';
